Video2ArabicSubs

حويل أي فيديو إلى ترجمة عربية (SRT / VTT) بضغطة واحدة — يعمل بدون إنترنت افتراضياً، بواجهة عصرية ثنائية اللغة لا تعلّق أبداً.

الإصدار v0.4.1 الرخصة MIT Windows + Linux Python + Whisper بدون إنترنت (محلي)
⬇️ تحميل وتثبيت كود المصدر على GitHub

التثبيت السريع

اختر الحزمة المناسبة لمنصتك وثبّت Video2ArabicSubs

🐧

لينكس (Debian / Ubuntu)

المستودع الرسمي عبر APT (يُنشَر على GitHub Pages)

echo "deb [trusted=yes] https://ragaeidos.website/video2arabicsubs/ stable main" \ # أضف المستودع
| sudo tee /etc/apt/sources.list.d/v2as.list
sudo apt update
sudo apt install v2as
جميع الإصدارات

بعد التثبيت: v2as (سطح المكتب) · v2as --web (تطبيق ويب على 127.0.0.1:7676) · v2as --lang en (إنجليزي).

💾

تحميل الحزم مباشرة

حزم تثبيت جاهزة لكل المنصة تُبنى تلقائياً عند كل إصدار.

v2as_0.4.1_amd64.deb ~1.1 MB · Debian/Ubuntu تحميل
v2as-0.4.1-linux-x86_64.run محمول · بدون صلاحيات تحميل
Video2ArabicSubs-Setup-0.4.1.exe مُثبِّت ويندوز تحميل
🖥️
تشغيل من المصدر
git clone https://github.com/RaGAEIDOS/video2arabicsubs.git
cd video2arabicsubs
pip install -r requirements.txt
python main.py
⚠️ أول تشغيل: يُنشئ البرنامج بيئة افتراضية خاصة بالمستخدم ويُثبّت المكتبات تلقائياً (يلزم: python3, python3-venv, python3-pip, python3-tk, ffmpeg). بعد ذلك يعمل بدون إنترنت نهائياً.
