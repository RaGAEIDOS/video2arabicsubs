## 🆕 المستجدات في الإصدار 0.3

- ✅ **فكرة أبسط ومحدَّدة**: اختر مجلداً أو فيديو **إنجليزياً** ← ترجمة **عربية فقط**، أو النص الإنجليزي **بدون ترجمة**.
- ✅ **🗑️ حُذف رفع النتائج إلى GitHub** بالكامل — لم يعد موجوداً في المشروع.
- ✅ **📁 مجلد حفظ تحدده أنت**: ضع مسار المجلد في الواجهة قبل البدء، وينسخ إليه البرنامج ملفات الترجمة (والفيديو المُحروق) فور انتهاء المعالجة — وتبقى النسخ محفوظة حتى بعد حذف المهمة.
- ✅ **ترجمة صامدة أمام حدّ سرعة Google**: طلبات مدموجة (٤٠ سطراً/طلب) + حدّ سرعة محلي + انتظار تصاعدي متدرج (حتى ~٤ دقائق) عند `429` + **زر إعادة المحاولة** يستأنف من آخر نقطة محفوظة دون إعادة تحويل الصوت.
- ✅ **ترجمة لا تتوقف أبداً**: إن تعذّر جوجل يتحول البرنامج **تلقائياً إلى مترجم محلي** (Argos Translate) ويُكمل الترجمة العربية بدون إنترنت، ثم يعود إلى جوجل تلقائياً بعد قليل — مع خيار صريح **«العربية (بدون إنترنت)»** في القائمة. يُحمَّل نموذج اللغة (~100MB) **مرة واحدة فقط**.
- ✅ **🔄 تشغيل أونلاين مجاني**: نشر جاهز على **Hugging Face Spaces** (Docker) — نفس الكود بالضبط.
- ✅ **واجهة أبسط**: لا لغة مصدر بعد الآن (الإنجليزية ثابتة)، وخيار واحد واضح: «العربية (ترجمة جوجل)» أو «الإنجليزية (بدون ترجمة)».
- ✅ **نماذج Whisper الأصلية فقط**: `tiny` / `base` / `small` / `medium` / `large` / `turbo` — بدون أي إضافات.

## 🚀 طريقة التشغيل

### المتطلبات الأساسية
- **Python 3.10+**
- **FFmpeg** (يُثبَّت تلقائياً عبر `imageio-ffmpeg`، ويمكن استخدام نسخة النظام)
- **اتصال بالإنترنت** (لأول تشغيل: تحميل نموذج Whisper + ترجمة Google)

### 1. تحميل المشروع

```bash
git clone https://github.com/RaGAEIDOS/video2arabicsubs.git
cd video2arabicsubs
```

### 2. تثبيت المكتبات

```bash
pip install -r requirements.txt
```

---

### 🌐 تشغيل تطبيق الويب (موصى به)

```bash
uvicorn web.main:app --reload
```

ثم افتح المتصفح على:

```
http://127.0.0.1:8000
```

> 🪄 عند أول تشغيل سيُحمَّل نموذج Whisper تلقائياً (~461 MB لنموذج `small`) إلى ذاكرة التخزين المؤقت. وإذا اخترت «العربية (بدون إنترنت)» أو دخل الاحتياط التلقائي، يُحمَّل **نموذج اللغة المحلية مرة واحدة** (~100MB) ثم تعمل الترجمة بدون إنترنت نهائياً.

**خطوات الاستخدام:**

1. **📁 ارفع الفيديو** — سحب وإفلات أو اختيار ملف (أو تبويب «رابط» إن ثبّت `yt-dlp`)
2. **⚙️ اختر الخيارات** — حجم النموذج، **لغة الترجمة** (جوجل · بدون إنترنت · إنجليزية)، صيغة الملف، حرق الترجمة، و**📁 مجلد الحفظ**
3. **▶ ابدأ الترجمة** — تابع المراحل والنسبة لحظياً
4. **✏️ عدّل وعاين** — صحّح النصوص والتوقيتات وشاهد النتيجة داخل المشغل (كل تعديل يُحدَّث فوراً في مجلد الحفظ أيضاً)
5. **⬇ حمّل** — ملف SRT/VTT (UTF-8) أو الفيديو المُحروق — والنسخة داخل مجلد الحفظ جاهزة دائماً

> 💡 **مجلد الحفظ** اختياري: اتركه فارغاً للاكتفاء بالتحميل من المتصفح. المسار يكون على الخادم (مثل `/home/you/Videos/subtitles` أو `C:\Users\you\Videos\subs`)، ويُنشأ تلقائياً إن لم يوجد.

> 💡 **تعذّر جوجل (too many requests)؟** لا مشكلة — البرنامج ينتقل **تلقائياً إلى المترجم المحلي** ويكمل الترجمة العربية بدون إنترنت (ولو انتهت النافذة يعود إلى جوجل وحده). وإن لم يكن المترجم المحلي متاحاً، اضغط **↻ إعادة المحاولة** لاحقاً — النص المُستخرج والترجمات المحفوظة لا تُعاد من البداية.

**متغيرات البيئة (اختيارية):**

| المتغير | الافتراضي | الوصف |
|---------|-----------|--------|
| `V2A_MAX_UPLOAD_MB` | `2048` | الحد الأقصى لحجم الملف المرفوع |
| `V2A_JOB_TTL` | `1800` | ثوانٍ قبل حذف نتائج المهام المنتهية تلقائياً |
| `V2A_MAX_CONCURRENT` | `1` | عدد المهام الثقيلة التي تعمل بالتوازي |
| `V2A_DATA_DIR` | `web/data` | مجلد تخزين الملفات المؤقتة والنتائج |

**دمج روابط الفيديو (اختياري):**

```bash
pip install yt-dlp
```

> بعد التثبيت يظهر تبويب «رابط» تلقائياً في الواجهة (`POST /api/url`).

**باستخدام Docker:**

```bash
docker build -t video2arabicsubs .
docker run -p 8000:76 -v v2a-data:/data video2arabicsubs
```

> نماذج Whisper تُخزَّن داخل فولم `/data` فتبقى بعد إعادة التشغيل. المنفذ الافتراضي `76` (اتفاق Hugging Face Spaces) ويمكن تغييره بـ `-e PORT=8000` مع `-p 8000:8000`.

### ☁️ النشر المجاني أونلاين (Hugging Face Spaces)

نفس الصورة تعمل أونلاين مجاناً على [Hugging Face Spaces](https://huggingface.co/spaces):

1. ارفع المشروع إلى مستودع (GitHub أو Hugging Face).
2. افتح [إنشاء Space جديد](https://huggingface.co/new-space)، اكتب الاسم، واختر **SDK: Docker** والموارد **CPU (Free)**.
3. اربط المستودع («Connect repository») واضغط **Create** — يبدأ البناء تلقائياً وينتهي خلال دقائق.
4. بعد البناء يفتح التطبيق على: `https://huggingface.co/spaces/<اسمك>/<المساحة>`

> 💡 إذا أنشأت مستودع Space فارغاً بدلاً من ربط مستودع جاهز، الصق هذا القسم في أول `README.md` الخاص به:

```yaml
---
title: Video2ArabicSubs
emoji: 🎬
colorFrom: indigo
colorTo: purple
sdk: docker
app_port: 76
pinned: false
---
```

**ملاحظات مهمة:**

- 🐳 الصورة تستمع على المنفذ **76** (اتفاق Spaces) — قابل للتغيير عبر متغير `PORT`.
- 🧠 نماذج Whisper تُحمَّل أول مرة وتُخزَّن في مجلد `/data` (التخزين الدائم للـ Space).
- ⏳ النسخة المجانية **تنام بعد فترة خمول** — أول طلب بعد الاستيقاظ يستغرق بضع ثوانٍ.
- 📦 حدّ الرفع عبر الموقع قد يقصر الفيديوهات الكبيرة — استخدم روابط الفيديو (`yt-dlp`) للفيديوهات الطويلة.

## 🌐 نقاط الـ API

| Method | Endpoint | الوصف |
|--------|----------|-------|
| `GET` | `/api/health` | القدرات والخيارات المتاحة |
| `POST` | `/api/upload` | رفع ملف + خيارات المعالجة → `job_id` |
| `POST` | `/api/url` | استقبال رابط فيديو (يتطلب `yt-dlp`) |
| `GET` | `/api/status/{job_id}` | لقطة JSON من حالة المهمة (بديل الاستعلام) |
| `GET` | `/api/events/{job_id}` | **بث SSE** للتقدم لحظياً |
| `GET` | `/api/subtitles/{job_id}` | الترجمات المُولَّدة (JSON) |
| `PUT` | `/api/subtitles/{job_id}` | حفظ التعديلات من المحرر |
| `GET` | `/api/download/{job_id}` | تحميل `srt` / `vtt` / الفيديو المُحروق |
| `GET` | `/api/video/{job_id}` | بث الفيديو المرفوع للمشغل (يدعم Range) |
| `POST` | `/api/cancel/{job_id}` | إيقاف مهمة قيد التشغيل |
| `POST` | `/api/job/{job_id}/retry` | إعادة تشغيل مهمة فاشلة/ملغاة مع **الاستئناف** (نص وترجمات محفوظة) |
| `DELETE` | `/api/job/{job_id}` | حذف مهمة وبياناتها فوراً |

> حقل اختياري `output_dir` في `/api/upload` و`/api/url`: مجلد على الخادم تُنسخ إليه الملفات الناتجة فور نجاح المهمة (وبعد كل تعديل من المحرر).
